连不上时的排查顺序

  1. 1WSL 装了吗？ 管理员 PowerShell 执行 wsl --status。没装就先执行 wsl --install -d Ubuntu-20.04，装完重启电脑。
  2. 2包装了吗？ 在 Ubuntu 窗口里解压并执行安装脚本： 
    tar -xzf parksim-jth-portable-<date>.tar.gz
cd parksim-jth-portable-<date>
sudo bash install.sh
    这一步会建 /media/step/data/Yccc7/ParkSim-JTH、装 ROS 依赖（包里自带 ROS 2 Foxy，不要 apt install ros-foxy-*）。
  3. 3服务起来了吗？ 在 Ubuntu 窗口里执行 bash /media/step/data/Yccc7/ParkSim-JTH/run.sh， 看到 serving on http://0.0.0.0:8099/ 才算好。 注意必须绑 0.0.0.0——WSL2 是 NAT，绑 127.0.0.1 时 Windows 侧访问不到。
  4. 4还是不通？ localhost 转发在「快速启动 / 休眠」之后可能失效。Windows PowerShell 里执行 wsl --shutdown，再重启服务。
  5. 5兜底：直接用 WSL 的 IP。 在 Ubuntu 窗口里执行 ip -4 addr show eth0（或 hostname -I）， 拿到例如 172.20.10.5，然后在上面输入框里填 http://172.20.10.5:8099/ 再点「探测这个地址」。
  6. 6Win11 22H2+ 还被拦？ 可能是 Hyper-V 虚拟防火墙。管理员 PowerShell： 
    Set-NetFirewallHyperVVMSetting -Name '{40E0AC32-46A5-438A-A0B2-2B479E8F2E90}' -DefaultInboundAction Allow
    或在 C:\Users\<你>\.wslconfig 里写 [wsl2] + firewall=false，然后 wsl --shutdown。
